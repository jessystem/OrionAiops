# Paleta ORION AIOps

Tema escuro, alinhado aos protótipos de interface.

| Uso | Hex | Aplicação |
|---|---|---|
| Fundo | `#0B1120` | Fundo das páginas |
| Cartão | `#1A2332` | Fundo de cartões e visuais |
| Borda | `#334155` | Divisórias e contornos |
| Primário | `#38BDF8` | Séries principais, destaques |
| Positivo | `#10B981` | Meta atingida, tendência favorável |
| Atenção | `#F59E0B` | Faixa de 75%, folga baixa |
| Crítico | `#EF4444` | Violação, faixa de 50% ou menos |
| Crítico escuro | `#7F1D1D` | Severidade máxima |
| Texto primário | `#F1F5F9` | Títulos e valores |
| Texto secundário | `#94A3B8` | Rótulos e legendas |

## Tipografia

* Títulos: Segoe UI Semibold, 16–20 pt
* Valores de cartão: Segoe UI Bold, 28–36 pt
* Corpo: Segoe UI, 10–12 pt

## Regras de uso

* Vermelho é reservado para violação de OLA e faixa de meta em risco. Não use como cor
  decorativa — perde o significado.
* Séries de P2 em `#F59E0B`, P3 em `#38BDF8`, mantidas consistentes em todas as páginas.
* Previsão sempre em linha tracejada; histórico em linha sólida.
